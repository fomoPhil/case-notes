What this takes, in build order

Everything lands in the one file, static/index.html. Tier 1 is pure CSS with zero logic risk. Tier 2 touches a little JS. Both tiers together are roughly one focused session.

Tier 1: pure CSS, no logic changes ~30 to 45 min, demo-safe

  • Layered background: soft radial sage wash plus a faint grain texture over the cream, and a warm gradient instead of a flat fill.
  • Shadows over borders: replace hairline card borders with layered shadow rings so cards sit on the page instead of being outlined on it.
  • Header brand moment: larger serif wordmark, italic serif subtitle, gradient hairline rule, lock icon in the privacy badge.
  • Monogram tiles on client cards, hover lift with arrow affordance, refined risk indicator.
  • Record button upgrade: gradient fill, inner highlight, concentric rings, breathing idle animation, real mic glyph, serif timer.
  • Document treatment for the note: letterhead, double rule, left-rule sections, tinted chips.
  • Detail pass: concentric radii on nested cards, custom checkbox styling, section label rules, ripple rings while recording.

Tier 2: small JS additions ~30 min, still low risk

  • Live waveform while recording, driven by an AnalyserNode on the mic stream you already have. Huge perceived-quality win for the demo.
  • Staged processing checklist replacing the spinner. Even timed optimistically (advance steps on a rough schedule, snap all to done when the response arrives), it reads as the pipeline working.
  • Letterhead date on the note from the plan payload.

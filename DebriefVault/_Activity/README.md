# Activity Log

This folder holds a dated record of what the Debrief app did on your behalf: the note it filed, what it booked, the email it drafted, and what its on-screen check saw.

Entries are written here automatically by the app after each executed debrief; you never need to create or edit them.

It is safe to read and annotate: add your own notes freely, the app only ever appends new entries and never rewrites what is already here.
